The first week of planning established the project's premise: a customizable,
widget-based dashboard for monitoring APIs and surfacing live data. This week's
deliverable is the project proposal itself, written to give the capstone advisor a
clear sense of the problem we are solving, who would use it, and the technology
direction we expect to take.

Notes worth flagging:

- The tech stack named in the proposal (React/Svelte frontend, JS backend, Redis +
  Postgres) was intentionally non-committal. The full technology decision is recorded
  later in the engineering documentation.
- "Downdetector" appears in the proposal as a possible integration; it was later
  dropped from scope when investigation showed no free public API exists.
